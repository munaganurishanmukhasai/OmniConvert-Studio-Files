# OmniConvert Studio

A private, browser-based image and PDF toolkit. The application runs in your browser and does not upload the files you process.

## Use it

1. Download `OmniConvert_Studio.html`.
2. Open it in a current desktop browser.
3. Choose a tool, add a file, set the options, and select **Start**.
4. Download the result from the results list.

The page is self-contained, including the photo enhancement model. An internet connection is needed to load supporting browser libraries from the configured CDNs. AI enhancement uses WebGPU when available and falls back to WebAssembly.

## Tools

- Convert image formats
- Combine photos into a PDF
- Export PDF pages as images
- Enlarge and enhance photos
- Resize images to a target file size

## Privacy

Files selected for conversion and enhancement are processed locally in your browser. The page loads supporting code libraries from public CDNs; the files you select are not sent to those services by the app.
